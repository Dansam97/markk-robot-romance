Entry for the make.fun bounty [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa). The program writes a single pickup line aimed at a robot or an AI to `entry.txt` in the output directory. The line turns on a machine-learning truth: a model's weights carry biases — and every one of this speaker's biases points at the addressee. No batteries, no charging, no rebooting; just weights, honestly confessed.

## Run it

```sh
python3 main.py
```
